# Experiments Directory

This directory will contain controlled experiments that compare coding agents and models using the same tasks.

## Planned Comparisons

Future experiments may evaluate:

- OpenCode + GPT
- OpenCode + Claude
- OpenCode + Gemini
- OpenCode + Kimi
- Codex
- Claude Code

## Evaluation Dimensions

Experiments will assess:

- **Task completion**: Did the agent finish the requested work?
- **Code correctness**: Does the generated code run and meet specifications?
- **Architecture**: Quality of the overall design and separation of concerns.
- **Security**: Presence of vulnerabilities or missing safeguards.
- **Testing**: Existence and adequacy of automated tests.
- **Hallucinations/API errors**: Invented functionality or incorrect API usage.
- **Human intervention**: Amount of manual correction required.
- **Execution time**: Time taken to produce the final artifact.
- **Token/cost efficiency**: Number of tokens consumed and associated cost.

Each experiment will be documented in its own subdirectory with a detailed report.
